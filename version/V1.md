# V1 — Basic Cloud Execution Platform

## Goal

Build a basic cloud execution platform that allows a GT student to submit and run workloads across our infrastructure.

## V1 Flow

```text
Student
   ↓
CLI / Web
   ↓
Control Plane
   ↓
Scheduling / Reconciliation
   ↓
Worker
   ↓
Data Plane
   ↓
Run Workload
   ↓
Monitor / Report
```

## V1 Includes

* CLI / Web clients
* Workload submission
* Worker registration
* Scheduling
* Resource management and monitoring
* Networking
* Service discovery and DNS
* Load balancing
* Self-healing / reconciliation
* Workload status and reporting
* Control Plane ↔ Data Plane communication

## Core Question

> **Can a student submit a workload, have the platform schedule and run it across our infrastructure, automatically handle failures, provide networking and service discovery, and let the student see what is happening?**
