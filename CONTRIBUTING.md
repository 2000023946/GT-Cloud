## Definition of Done

Every meaningful adapter/component must have:

- [ ] Functional tests
- [ ] Failure/error tests
- [ ] ≥95% test coverage
- [ ] Logging
- [ ] Metrics
- [ ] Documentation
- [ ] Clean separation of responsibilities
- [ ] No unnecessarily large files
- [ ] Readable, maintainable code

When applicable:

- [ ] Concurrency tests
- [ ] Performance/load tests
- [ ] Integration tests
- [ ] End-to-end tests
